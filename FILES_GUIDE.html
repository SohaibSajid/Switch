Virtual Switch - what every file does

Operating Systems, Fall 2026 - Muhammad Sohaib Sajid, BSAI24043

How to read this guide

The project has three tiers. Tier 1 is the core switch (frames over TCP, queues, broadcast sharing, MAC table, port limit). Tier 2 adds the advanced features (priorities, rate limit, VLANs, mirroring, live changes, the swctl admin tool, signals, logging). Tier 3 is the bonus (two switches, supervisor, benchmark).

Many files were written in Tier 1 and then extended in Tier 2 or 3. In the tables, the Tier column says where the file started, and the last column says what was added later, so you can see both the original job of the file and what changed. Colours:  Tier 1   Tier 2   Tier 3   tests / docs 

1. Programs and how the files fit together

ProgramBuilt fromWhat it is
switchswitch.c + frame, net, pkt, queue, mac_table, config, shm_stats, logThe switch itself: one process with many threads.
hosthost.c + frame, netA test host that connects to the switch, sends and prints frames.
swctlswctl.c + net, frame, shm_statsThe admin tool, a separate process.
switch_pair, supervisor, benchtheir own .c filesThe three bonus programs.
test_maintest_main.c + frame, mac_table, pkt, queue, logUnit tests.

Lowest layer first: sync.h (checked locks) and frame (the header) are used by everything; net reads and writes frames on sockets; pkt is one shared frame in memory; queue holds the frames waiting for a port; mac_table remembers which MAC is on which port; switch.c ties all of them together with the threads.

2. Core library files (start in Tier 1)

FileTierWhat it doesChanged later
frame.h
frame.c		Tier 1Defines the 17-byte header (length, src, dst, vlan, priority) and packs/unpacks it with htons/ntohs into a byte buffer, not a struct, so there is no padding problem. Also MAC helpers: parse "02:..:0A", print, test for broadcast. Rejects a length over 1500 or a priority over 2.Not changed. The vlan and priority fields that were already in the header are what Tier 2 uses.
net.h
net.c		Tier 1 (item 1)read_full and write_full loop until all bytes are done (partial reads and writes, retry on EINTR). frame_read reads the 17-byte header, then exactly length payload bytes. frame_write sends a whole frame.Tier 3: added versions that also wake on a second file descriptor (read_full_w, write_full_w, frame_read_w). They are needed for the pipe link between two switches, because a pipe has no shutdown().
pkt.h
pkt.c		Tier 1 (item 3)One frame stored once in memory with a reference count under a mutex. pkt_ref adds a user, pkt_unref removes one, and the last one frees the frame. This is how a broadcast goes into many queues without being copied.Not changed.
sync.hTier 1Small inline wrappers (lock, unlock, cond_wait, cond_signal, cond_broadcast) that abort with a message if the call fails, so every return value is checked.Not changed.
queue.h
queue.c		Tier 1 (item 2), rewritten in Tier 2Tier 1: one bounded output queue per port, a mutex and a condition variable. queue_push never blocks and drops the frame (counted) if full; queue_pop sleeps until there is a frame; queue_close wakes the sender and drops what is left.Tier 2, item 6: three rings (high, normal, low); queue_pop picks by weighted round robin 5:3:1 and by aging (a normal or low frame older than 200 ms goes first, never twice in a row). Item 7: token bucket (queue_set_rate, queue_refill); a sender without tokens waits with pthread_cond_timedwait. Item 10: queue_flush empties a queue when a port changes VLAN.
mac_table.h
mac_table.c		Tier 1 (item 4), extended in Tier 2 and 3Tier 1: hash table with one lock per bucket (striped locking). Learns the source MAC, looks up the destination, logs "MAC moved", ages old entries (aging thread calls mac_table_age), evicts the least recently used entry at K entries, and allows at most M MACs per port (port security).Tier 2: the trunk port is exempt from the per-port limit (item 8); mac_table_clear takes all bucket locks in order and mac_table_flush_port removes one port's MACs (item 10); messages go to the logger (item 13); 32 buckets because ThreadSanitizer cannot track 64 held locks. Tier 3: entries live in a fixed pool linked by index, mutexes are robust and process-shared, and there are functions to create, attach to and repair the table in shared memory (the supervisor uses them).
config.h
config.c		Tier 1, extended in Tier 2Reads the config file (key = value, # comments) and checks every value. Tier 1 keys: age, max_macs, macs_per_port, wait. An error rejects the whole file.Tier 2: new keys rate, weights, qos_age, trunk and per-port vlan.N, rate.N, mirror.N. Used by SIGHUP reload (item 12).

3. The programs themselves

FileTierWhat it doesChanged later
switch.cTier 1 core, most of Tier 2Tier 1: listens on the TCP port; each accepted host gets a port with a receiver thread (reads frames, learns, looks up, forwards) and a sender thread (writes from its queue); flooding for unknown or broadcast destinations; the port semaphore with sem_timedwait and the "switch full" reply; the aging thread; clean shutdown.Tier 2: VLAN rules in forwarding and the trunk port (8); mirroring (9); per-port locks and the documented lock order, admin operations shutdown/up/vlan/trunk/mirror/rate (10); the admin UNIX-socket thread and its commands (11); signal thread with sigwait for SIGINT, SIGHUP, SIGUSR1 (12); token-refill timer thread (7); logger calls (13); waiter threads so hosts waiting for a port do not queue one behind another. Tier 3: option -t (pipe link as the trunk port) and -M (MAC table in shared memory).
host.cTier 1 (test tool)The test host: connects to the switch, a receiver thread prints incoming frames, and commands from stdin send frames (send, slow byte by byte, burst, half a frame, vlan, pri, src, sleep). Used by all tests.Not changed. Its vlan and pri commands were already there for Tier 2.
swctl.cTier 2 (item 11)The admin tool. Sends one command over the UNIX domain socket and prints the reply (exit status 1 on an error). stats and stats --watch read the counters directly from shared memory instead.Started before the final work with show mac, show ports, clear mac, stats. Extended with the usage text for shutdown, up, vlan, trunk, mirror, rate (the switch carries them out).
shm_stats.h
shm_stats.c		Tier 2 (item 11)The live counters per port (frames in, out, dropped, mirrored) in a POSIX shared memory object, protected by a process-shared mutex (PTHREAD_PROCESS_SHARED, robust). The switch creates and updates it; swctl maps and reads it.Port limit raised to 66 (64 hosts plus the link).
log.h
log.c		Tier 2 (item 13), newThreads put messages on a queue (log_msg, never waits for the disk); one logger thread writes them with timestamps to the log file. If the logger is not running, messages go to stderr.New in Tier 2. Used by switch.c and mac_table.c.

4. Bonus programs (Tier 3)

FileTierWhat it does
switch_pair.cTier 3Creates two pipes (one for each direction) and starts two switches, each with -t read_fd,write_fd. Each switch treats its pipe end as an extra trunk port, so hosts on switch A reach hosts on switch B and each side learns the other's MACs behind the trunk. Gives each switch its own admin socket, stats object and log named after its TCP port.
supervisor.cTier 3Creates the MAC table in shared memory, starts the switch with -M (fork/exec), and restarts it with waitpid when it dies from a signal. The new switch checks the table and carries on with what the old one learned. SIGINT/SIGTERM stop everything cleanly.
bench.c
bench_plot.py
bench_10pct.csv
bench_1pct.csv
bench_results.svg		Tier 3bench.c is the multithreaded load generator: lookups and learns on one hash table with one global lock, striped locks, or a read-write lock. The two CSV files are its results (10% and 1% learns), bench_plot.py draws them, bench_results.svg is the graph used in the report.
